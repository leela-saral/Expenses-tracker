# Pennywise — Expense Tracker

A responsive expense tracker built with HTML, CSS, and JavaScript. Record income and expenses, categorize transactions, and track your available balance.

## Features
- Add income and expense records
- Choose a category and date
- Automatically calculate income, expenses, and balance
- Filter transactions by type
- Delete individual transactions or clear all records
- Responsive layout for mobile and desktop
- Save records in browser local storage

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a description, amount, type, category, and date.
4. Click **Add transaction**.

No installation or API key is required.

## Privacy note
Transactions are stored in local storage in the browser on the device where they are entered. They are not synced to an account or stored in GitHub. Clearing browser data may remove records. This is a learning project, not a banking application.
